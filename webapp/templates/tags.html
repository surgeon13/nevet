Setting up a tag

  1. NFC sticker (NTAG213/215): write the tag's link to it as a URL record, with a phone app like NFC Tools, or with the Flipper Zero (download Flipper .nfc, copy it to the Flipper's nfc folder; the Flipper can also emulate it so you can test a phone tap first). Phones then open the tag by themselves.
  2. Key fob (125 kHz): download Flipper .rfid and write it onto a blank T5577 fob with the Flipper (125 kHz RFID → Saved → Write). Or scan an existing fob at the reader and link it from “Scanned, not linked yet”.
  3. At the gate: plug the Flipper (or a USB card reader) into the Pi and run nevet tags reader. Scan your hero fob, then tap a tag: it's logged as you. A fob alone checks you in to the event that's on.
  4. No chip? Print the QR label; scanning it does the same as a tap.
